<h1>A Music Player For Your Terminal</h1>

<p>Tusic is a music player written in go.</p>
<p>Relies on MPV for audio, uses an IPC server at /tmp/tusic.sock</p>
<p>Supports opening any folder, defaults to ~/Music</p>

<h2>Building</h2>

<p>Clone the repo, cd in, `go build -o tusic && tusic`</p>
